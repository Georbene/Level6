# 🌟 Level 6 Projects Collection

Welcome to my **Level 6 Projects** repository!  
This repository contains **4 interactive web applications**, each demonstrating a core JavaScript data structure and its real-world application. All projects are deployed live on [Vercel](https://vercel.com/).

---

## 📂 Projects Overview

| Project | Description | GitHub Source | Live Demo |
|---------|-------------|---------------|-----------|
| **Contacts App Manager (Map-Based)** | A contact management system where you can add, view, and manage contacts. It visualizes contacts on a map and uses **JavaScript Map** to store and retrieve unique contacts efficiently. | [📂 GitHub](https://github.com/Georbene/Level6/tree/master/Contacts%20App%20Manager%20(Map-Based)) | [🌐 Demo](https://level6-tau.vercel.app/Contacts%20App%20Manager%20(Map-Based)/) |
| **Task Scheduler (Queue-Based)** | A task scheduling app that processes tasks in **FIFO (First In, First Out)** order. It uses a **Queue** to manage pending tasks and a processing log to track completed tasks. | [📂 GitHub](https://github.com/Georbene/Level6/tree/master/Task%20Scheduler%20(Queue-Based)) | [🌐 Demo](https://level6-tau.vercel.app/Task%20Scheduler%20(Queue-Based)/) |
| **Undo–Redo System (Stack-Based)** | A text editor implementing **undo** and **redo** functionality using **Stacks (LIFO)**. Each action is recorded and can be reverted or reapplied, demonstrating stack operations in practice. | [📂 GitHub](https://github.com/Georbene/Level6/tree/master/Undo%E2%80%93Redo%20System%20(Stack-Based)) | [🌐 Demo](https://level6-tau.vercel.app/Undo–Redo%20System%20(Stack-Based)/) |
| **Unique Visitor Tracker (Set-Based)** | Tracks unique visitors by storing visitor IDs in a **Set**, preventing duplicates automatically. It provides stats like total visitors, recent visitors, and duplicates prevented. | [📂 GitHub](https://github.com/Georbene/Level6/tree/master/Unique%20Visitor%20Tracker%20(Set-Based)) | [🌐 Demo](https://level6-tau.vercel.app/Unique%20Visitor%20Tracker%20(Set-Based)/) |
